# Utility Modes

!!! warning "Developer Tools"
    These modes are developer/diagnostic tools not intended for end-user display.

| Mode | Purpose |
|------|---------|
| [testfonts](testfonts.md) | Renders all available bitmap fonts at their native sizes for visual verification of font generation output. |
| [testicons](testicons.md) | Displays all registered Material Symbols icons in a grid layout for validating icon extraction and rendering. |
| [testwidgets](testwidgets.md) | Exercises all reusable UI widget components (borders, progress bars, sparklines) in a single diagnostic view. |
| [testpattern](testpattern.md) | Generates geometric validation patterns (color bars, grayscale ramps, grid lines) for display calibration. |
