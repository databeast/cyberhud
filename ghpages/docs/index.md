# CyberHUD Documentation

Welcome to the documentation for **cyberhud** — a daemon that drives SPI and I2C displays on Raspberry Pi. It supports LCD, OLED, e-ink, and LED matrix panels with configurable display modes, GPIO monitoring, and systemd integration.

An easy no-code solution to all those PI Display HATs you have lying around, to finally build that mini-cyberdeck you keep thinking about.

Modern linux code, zero dependencies, two binary files.

- [Display Modes](display-modes/index.md) — All 28 built-in display modes including informational dashboards, attract mode screensavers, and interactive menus

CyberHUD includes nine attract modes — ambient visual effects like bokeh, plasma, and starfield that activate automatically during idle periods to keep your panel visually engaged. Each mode's documentation page includes snapshot previews at representative resolutions.
